# 💡 逆向选择

> 🏷️ 一句话：交易之前，最想成交的往往是你最不该做的那笔生意——"坏人最积极进门"。

## 🧭 四问
- ❓ **是什么**：交易前因[[信息不对称]]产生的劣质客户驱逐优质客户现象。典型如阿克洛夫柠檬市场：买方只愿按平均质量出价，好卖家觉得亏就退出，市场里剩下的越来越差。
- 🗣️ **大白话**：二手车市场，好车车主舍不得贱卖，走了；烂车车主抢着挂牌。你按"平均车况"出价，买到的十有八九是烂的。信贷市场同款：真正稳健、不缺钱的人对高利率不敏感，敢借高利贷的往往是最可能跑路的人——利率越高，屋里坐的越敢赌。
- ⚙️ **底层机制**：价格（利率）承担了双重角色——既是报价，又是筛选器。抬高价格把"好人"挤出去、把"坏人"拉进来，风险逆向选择；理性的出资方因此宁可不借，也不愿提价。
- ⚠️ **争议 / 易错**：时间点别记反——**逆向选择在交易发生之前**（谁来敲门），[[道德风险]]在交易发生之后（拿了钱干啥）。另外，利率不是万能药：提价看似补风险，实则招来最敢赌的人，所以银行用[[信贷配给]]、抵押、筛选代替单纯抬价。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 🍋 柠檬市场模型（Akerlof）：买方按期望质量出价 → 高质量卖家退出 → 平均质量下移 → 出价再降 → 进一步退出……极端下市场萎缩乃至消失。
- 🏦 信贷市场推论：银行面对的借款人中，利率越高，剩余人群的平均违约倾向越高 → 银行预期收益在某个利率后反而下降。
- 🛠️ 药方：①私人信息生产与声誉；②[[抵押品]]——坏项目拿不出等值抵押，自动退出竞争；③金融中介专业化筛选；④信号发送（好企业愿付出代价证明自己）。
- 📌 结论：逆向选择解释了为什么股票债券市场对中小企业关闭——它们信息不透明，市场宁愿不给钱。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 🧊 隐藏假设：买方"知道自己不知道"，所以按平均出价。现实中更糟的是过度自信——双方都觉得自己的项目好，筛选更难。
- ⚠️ 翻车点：把"客户主动上门、抢着借"当好事。越饥渴的借款人，越可能是逆向选择的猎物；银行销售压力大时尤其容易放松标准去"抢量"。
- 🌰 危机现场：[[2008次贷危机]]前，房贷审批"NINJA 贷款"（无收入无工作无资产也批），正是筛选环节失守——最该被拦在门外的人，批量进了门。
- 🔗 连锁暗线：逆向选择 → [[信贷配给]]（不借就是不借，加价没用）；抵押品缩水 → 逆向选择加剧 → 企业融资更难 → [[金融加速器]]放大衰退。
