# 💡 金融加速器

> 🏷️ 一句话：经济里的"恶性循环放大器"——越穷越借不到，越借不到越穷。

## 🧭 四问
- ❓ **是什么**：伯南克等人提出的机制——借款人净值（含[[抵押品]]）顺周期波动，通过外部融资溢价把小冲击放大成大周期。链条：净值↓ → 外部融资溢价↑ → 投资↓ → 经济↓ → 净值再↓。
- 🗣️ **大白话**：经济刚有点冷，企业赚得少了、股票房子也跌了——银行一看你的家底薄了，"抵押品不够啊"，贷款条件立刻收紧。你被迫缩投资、裁员，经济更冷，你家净值更薄……一开始只是打了个喷嚏，加速器让经济得了场重感冒。
- ⚙️ **底层机制**：[[信息不对称]]使外部融资比内部融资贵（外部融资溢价），溢价大小取决于借款人净值：净值高＝自己的钱押得多＝[[道德风险]]小＝溢价低。资产价格下跌同时打击净值与抵押品，溢价跳升，信用收缩，投资与产出进一步下滑——反馈回路自我强化。
- ⚠️ **争议 / 易错**：加速器不是"银行太胆小"，而是信息不对称下的必然放大机制，对小企业、依赖银行贷款的部门尤其猛。别把它当"普通衰退"——它的关键特征是"小冲击→大波动"，且在资产负债表被修复前，靠降息未必够。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 🔁 核心链条：**净值↓ → 外部融资溢价↑ → 投资↓ → 总需求↓ → 收入/资产价格↓ → 净值↓**（自我强化）。
- 📐 关系式：外部融资溢价 ＝ f(借款人净值)，净值与溢价负相关；净值同时受留存收益与资产估值影响。
- 🧩 信息基础：净值高＝借款人"利益对齐"强＝[[道德风险]]与[[逆向选择]]成本低，这是加速器的微观地基。
- 📌 含义：小冲击（利率升、油价涨、资产价格回调）经过信用市场放大，产出与就业波动被数倍放大——金融市场不是被动反映经济，而是主动制造波动。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 🧊 隐藏假设：外部融资溢价可观测、净值可快速重估。现实中它是非线性的——正常时期平缓，危机时断崖式跳升，模型线性外推会严重低估尾部。
- 🌰 历史现场：[[大萧条]]的债务通缩（费雪）是加速器的 1.0 版——物价跌→实际债务升→净值崩→银行挤兑→信贷冻结；[[2008次贷危机]]是 2.0 版——房价跌→抵押品负资产→CDO/CDS 链条断裂→全球信用骤停。
- ⚠️ 翻车点：以为央行降息就能解开加速器——净值和抵押品价格在跌，利率渠道被抵押品渠道压住；这就是为什么危机应对要直接扩[[抵押品]]、注资本、买资产（QE、[[最后贷款人]]）。
- 🔗 与[[流动性螺旋]]、[[明斯基时刻]]的暗线：加速器管"企业端净值"，流动性螺旋管"机构端抛售"，明斯基管"杠杆累积"——三者合流，就是完整的金融危机剧本。
