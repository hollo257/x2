# 💡 货币危机

> 🏷️ 一句话：政府想把汇率钉住，资本却抢着外逃，外储被抽干，汇率崩盘式贬值。

## 🧭 四问
- ❓ **是什么**：货币危机（Currency Crisis）——在固定（或盯住）汇率制下，市场对本币信心崩塌，资本大规模外逃，央行动用外汇储备护盘失败，被迫放弃盯住、汇率大幅贬值。
- 🗣️ **大白话**：老百姓和老外都觉得"这钱要贬"，争先恐后把本币换成美元跑掉。央行拿外储去托盘，外储越打越少，最后打光了，汇率像脱缰野马往下跳。
- ⚙️ **底层机制**：固定汇率 + 资本外流 + 预期自我实现。大家都觉得要贬→抢汇→央行外储↓→更守不住→真贬，预期自己兑现。根子常是[[不可能三角]]的硬伤。
- ⚠️ **争议 / 易错**：别只怪"投机者恶意做空"。很多危机是基本面（经常账赤字、财政货币化、外债过高）先烂了，炒家只是临门一脚；预期一旦转负，就是多重均衡里的坏均衡。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 触发条件：固定汇率 + 资本外流压力 + 央行外汇储备不足。
- 演化：本币遭抛→央行买本币抛外储→外储耗尽→放弃盯住→汇率暴跌。
- 对策：资本管制、让汇率浮动、向 IMF 求助救助。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 它和[[银行挤兑]]同构：都是"先到先得+预期自我实现"的多重均衡——你觉得要贬就先跑，跑的人多了就真贬。
- 第一代模型怪财政赤字货币化（政府印钱补赤字，钱贬是注定）；第二代模型怪预期自我实现（基本面还行但信心崩了也能爆）；新兴市场多是银行+货币双危机（"双重危机"）。
- 固定汇率是[[名义锚]]，锚一断，[[通胀预期]]跟着脱锚，输入性通胀一起来。
- 危机后本币大贬，外债多的企业以本币计的债务暴涨，资产负债表被打穿——接棒[[资产负债表衰退]]。
