# 💡 不可能三角

> 🏷️ 一句话：固定汇率、资本自由流动、独立货币政策——三个只能挑两个，要兼得就得崩。

## 🧭 四问
- ❓ **是什么**：不可能三角（Mundell Trilemma / 三元悖论）——开放经济下，固定汇率制、自由资本流动、独立货币政策三者不可兼得，必须放弃其一。
- 🗣️ **大白话**：鱼和熊掌不可兼得。你想把汇率钉死、又想让钱自由进出、还想自己定利率，央行分身乏术——一旦外国加息，你为守汇率就得跟着加，独立货币政策当场交白卷。
- ⚙️ **底层机制**：资本自由流动下，[[利率平价]]把国内外利差钉死；你若又选了固定汇率，就只能放弃独立货币政策，跟着锚定国走；要保独立货币政策，就得搞资本管制或让汇率浮动。
- ⚠️ **争议 / 易错**：不是"选了就一劳永逸"，而是代价在哪一头。选固定+自由流动，把货币政策交出去；选独立+固定，就得把资本管住；选独立+自由流动，汇率就得让它飘。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 三选二：
  - 固定汇率 + 资本自由流动 → 放弃独立货币政策（如港币联系汇率、欧元区）。
  - 固定汇率 + 独立货币政策 → 必须资本管制。
  - 资本自由流动 + 独立货币政策 → 汇率必须浮动。
- 框架来自开放经济政策权衡（米什金第18章）。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 潜台词：很多新兴市场嘴上选"固定+独立"，暗地里靠资本管制勉强撑——管不住就爆雷。
- 翻车点：半吊子最危险。名义固定、实际又想独立、资本又半开，投机者一旦赌你守不住，[[货币危机]]立刻上门。
- 欧元区就是"固定汇率（统一货币）+资本自由流动"的极端版，代价是成员国放弃独立货币政策，一遇冲击只能苦熬——[[欧债危机]]的制度根源。
- 它和[[名义锚]]互为表里：把汇率当锚，就是主动交出一部分货币政策独立性。
