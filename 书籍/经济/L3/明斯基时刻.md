# 💡 明斯基时刻

> 🏷️ 一句话：好日子太舒服，大家的融资从"能还本付息"一步步滑到"只够付利息"再到"靠涨价还债"，崩在一瞬间。

## 🧭 四问
- ❓ **是什么**：明斯基时刻（Minsky Moment）——长期繁荣催生过度乐观与杠杆，融资结构从对冲融资→投机融资→庞氏融资逐级恶化，一旦资产价格掉头，债务链断裂、危机爆发的那个转折点。
- 🗣️ **大白话**：经济好太久，人就飘了。一开始借钱还能连本带息还（对冲），后来只够付利息得靠滚续（投机），最后连利息都付不出，全指望资产涨价套现（庞氏）。哪天价格不涨了，整盘棋崩。
- ⚙️ **底层机制**：稳定本身制造不稳定——繁荣期风险偏好↑、杠杆↑、抵押品价格↑、信贷↑。融资三阶段演化到庞氏段后，利率一升或资产价一跌，被迫甩卖→价格崩→危机。
- ⚠️ **争议 / 易错**：明斯基说金融不稳定是**内生**的（不是外生冲击），这和有效市场派针锋相对；"时刻"难预测但可识别，别当成精确择时工具。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 三类融资：
  - 对冲融资：现金流足以还本付息。
  - 投机融资：现金流只够付息，本金靠滚续。
  - 庞氏融资：连利息都不够，靠资产涨价套现。
- 稳定→乐观→加杠杆→庞氏化→反转，构成内生周期。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 潜台词："这次不一样"是最危险的四个字——繁荣越久，人越相信结构变了，恰恰滑向庞氏。
- 和[[金融加速器]]咬合：资产价↑→净值↑→信贷更松→杠杆更高，正反馈到庞氏段；反转时反向放大。
- 翻车点：庞氏段一遇到利率上升或现金流不及预期，立刻触发[[流动性螺旋]]（甩卖-抵押品折扣循环），危机比想象快。
- 它解释了[[2008次贷危机]]：房价只涨的信念→次贷+CDO 层层包装成庞氏→房价一停，链条断。
