# 💡 流动性螺旋

> 🏷️ 一句话：缺钱被迫甩卖资产→价格跌→抵押品不值钱→更借不到钱→再甩卖，越陷越深的死循环。

## 🧭 四问
- ❓ **是什么**：流动性螺旋（Liquidity Spiral）——在去杠杆压力下，机构被迫低价甩卖资产换取流动性，甩卖压低资产价格，抵押品价值下跌、融资能力进一步收缩，被迫甩卖更多，形成"甩卖-降价-再甩卖"的正反馈螺旋。
- 🗣️ **大白话**：你急用钱，只好把手里的房子股票低价抛。你一抛价格更低了，银行一看你押的东西贬值，敢借给你的钱更少了，你只好再抛……雪球越滚越大，好东西也砸成白菜价。
- ⚙️ **底层机制**：两环相扣——**损失螺旋**（资产价↓→净值↓→被迫减仓→价更↓）+ **保证金/抵押品螺旋**（价↓→haircut↑→能融的钱↓→更被迫卖）。影子银行无存款保险、靠回购短融，最易触发。
- ⚠️ **争议 / 易错**：这不是"基本面崩了"，是**流动性挤兑**——资产本身可能没那么差，只是被强制贱卖。所以央行得当"最后做市商"直接下场买，而不只是[[最后贷款人]]给钱。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 链条：缺钱 → 甩卖 → 价格↓ → 抵押品折扣(haircut)↑ → 融资↓ → 再甩卖。
- 回购市场 haircut 飙升 → 去杠杆 → 甩卖（源文件明示）。
- 对策：央行注入流动性、直接买资产（最后做市商）。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 潜台词：它和[[银行挤兑]]同构，但发生在**影子银行**——回购、货币基金、SPV，没有存款保险，靠抵押品融资，挤兑形式就是 haircut 飙升。
- 它是[[明斯基时刻]]的"最后一公里"：庞氏段一旦反转，不是慢慢跌，而是螺旋式甩卖，几天内流动性枯竭。
- 和[[金融加速器]]、[[资产负债表衰退]]连成片：甩卖→净值↓→信贷↓→需求↓→资产价更↓。
- 教训：单家机构"稳健"不代表系统稳健（微观审慎的盲区），得靠[[宏观审慎]]和央行做市商兜底；2008 年央行下场买 MBS 就是打断螺旋。
