# 💡 资产负债表衰退

> 🏷️ 一句话：资产价格崩了，企业居民全被债务套住，目标从"赚钱"变成"还债"，再低的利率也没人借钱。

## 🧭 四问
- ❓ **是什么**：资产负债表衰退（Balance Sheet Recession，辜朝明提出）——资产泡沫破裂后，私人部门资产端缩水、负债端不变，技术上资不抵债，于是集体把目标从利润最大化切换为"负债最小化"，埋头还债、停止借贷和支出。
- 🗣️ **大白话**：房价/股价一崩，大家发现自己欠的债比手里资产还多。于是全民勒紧裤腰带先还债，不消费、不投资、不借钱。央行把利率降到零也没用——没人愿意再借了。
- ⚙️ **底层机制**：资产价↓ → 净值↓ → 企业居民优先修资产负债表、削减支出/投资 → 总需求↓ → [[IS-LM]] 里 IS 曲线整体左移塌缩。此时货币政策失效（[[流动性陷阱]]），只有财政持续花钱才能填需求窟窿。
- ⚠️ **争议 / 易错**：它不是普通衰退。普通衰退靠降息就能救；资产负债表衰退里**借款人消失了**，再便宜的钱也借不出去。误判成普通衰退、急着财政紧缩，会把日本式长期停滞再演一遍。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 触发：资产价格暴跌 → 资产 < 负债，私人部门技术性资不抵债。
- 行为转变：目标函数 = 负债最小化，而非利润最大化。
- 政策含义：货币政策失效（无人借钱），需财政扩张填补需求缺口。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 潜台词：借钱的人不是因为没信用，而是因为"不想再借"——传统[[货币乘数]]和信贷渠道整个失灵，钱趴在银行体系里。
- 它和[[流动性陷阱]]是一体两面：日本同时是资产负债表衰退+零利率，所以光放水救不了，得财政持续托底。
- 危险操作：危机后急着搞财政整顿/紧缩，需求直接二次塌陷——[[大萧条]]和欧债 periphery 的紧缩教训。
- 与债务通缩（费雪）同源：越还债、物价越跌、实际债务越重，恶性循环。修复资产负债表往往要十年以上。
