# 💡 道德风险

> 🏷️ 一句话：交易做完之后，拿到钱的人可能就开始乱来——"反正亏的不全是我的"。

## 🧭 四问
- ❓ **是什么**：交易后因[[信息不对称]]产生的代理人行为偏离委托人利益的问题：借款人/受保方拿到钱或拿到保障后，倾向于从事对自己有利、对出资方危险的活动，又称委托代理问题。
- 🗣️ **大白话**：买了全额车险的人开车敢走神；银行知道政府会兜底，放贷就敢闭眼。钱一到手，激励就歪——这就是道德风险。和[[逆向选择]]的区别：那是"进门之前谁混进来"，这是"进门之后他干了啥"。
- ⚙️ **底层机制**：代理人（经理/借款人/银行）掌握行动信息，委托人（股东/债权人/存款保险）监督要成本；收益归自己、成本外部化时，冒险激励自我膨胀。合同设计（剩余索取权、清算威胁、[[抵押品]]、监督）就是在压这个歪。
- ⚠️ **争议 / 易错**：时间点别记反——道德风险在**交易完成之后**。另一个翻车点：别把它只当成"坏人作恶"，它是激励结构问题——[[存款保险]]本意防挤兑，却让银行更敢冒险；救助"大而不能倒"机构，同样种下明天的道德风险。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 🧩 股权融资中的道德风险：委托代理——经理不是股东本人，努力省了、在职消费、帝国建造，股东监督成本高（搭便车的小股东更不会管）。
- 🧩 债务融资中的道德风险：借款人倾向于投高风险项目——赚了归自己，亏了有债权人分担（有限责任）；这就是为什么债务合同常要求[[抵押品]]、加契约约束。
- 🛠️ 药方：净值与抵押要求、限制性契约（不许乱投资、维持财务比率）、银行专业化持续监督、声誉机制、监管资本要求。
- 📌 结论：道德风险的存在，使债务合同天然是"抵押＋监督＋契约"的组合，而非一张借条了事。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 🧊 隐藏假设：监督"做得过来"。当规模、复杂性、创新速度超过监督能力（结构化产品、表外 SPV），道德风险就从"可控"变成"系统性"。
- 🌰 翻车现场一：[[2008次贷危机]]——"发起—分销"模式下，发起人把贷款打包卖走，自己不再承担风险，监督激励蒸发，审批标准形同虚设。
- 🌰 翻车现场二：[[存款保险]]与"大而不能倒"——预期被救的机构，杠杆和风险偏好双双上移，监管越承诺兜底，明天的雷越大。
- ⚠️ 两难潜台词：金融稳定政策本身在制造道德风险——[[最后贷款人]]救的是流动性危机，一旦被当成"保本"，市场纪律就死了；监管永远在"防挤兑"与"防冒险"之间走钢丝。
- 🔗 与[[金融加速器]]的暗线：净值越高，借款人"自己的钱押在里面"，道德风险越小、外部融资越便宜；反之亦然——这正是加速器的微观机制。
