# 💡 费雪效应

> 🏷️ 一句话：名义利率 ≈ 实际利率 ＋ 预期通胀——钱价里必须把"钱会贬值多少"先扣掉。

## 🧭 四问
- ❓ **是什么**：欧文·费雪提出的名义利率与实际利率关系：**i ≈ r ＋ πᵉ**（名义利率＝事前实际利率＋预期通胀率）。通胀预期上升，名义利率随之上升，实际利率由真实经济因素决定、大体独立于货币。
- 🗣️ **大白话**：你借钱出去，心里想赚的是"东西变多"，不是"纸币变多"。所以一旦预计明年物价涨 3%，你报价时自动在真实利息上再加 3%——不然白借了。这就是费雪效应：通胀预期是名义利率的"加价单"。
- ⚙️ **底层机制**：借贷双方签的是名义合约，但决策看实际购买力；理性借贷会在名义利率里嵌入通胀预期补偿，使事前实际利率 r＝i－πᵉ 不被通胀侵蚀。长期价格灵活、货币中性下，货币扩张不影响 r，只抬高 i。
- ⚠️ **争议 / 易错**：短期费雪效应很弱！工资价格粘性、预期调整慢，名义利率不会立刻跟着通胀预期走；长期才同步。另外，事后实际利率（i－π）可能为负（存款跑输通胀），别把"名义利率高"当成"实际回报高"。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 🧮 核心公式：**i ≈ r ＋ πᵉ**（近似式；精确式 1＋i＝(1＋r)(1＋πᵉ)）。
- 📌 名义利率 i：合同/报纸上看到的利率；实际利率 r＝i－πᵉ，分事前（按预期通胀）与事后（按实际通胀）两种。
- 📌 长期结论：货币数量增加 → 通胀预期 πᵉ 上升 → 名义利率 i 上升（长期费雪效应成立）。
- 📌 现实读数：名义利率 5%、通胀预期 3%，事前实际利率约 2%——这才是存钱/借钱的真实账。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 🧊 隐藏假设：预期是"事前"形成的，且借贷双方都懂这个公式。现实中普通人经常"货币幻觉"——只看名义利率，忘了通胀。
- ⏱️ 短期失灵：凯恩斯主义强调短期价格粘性，名义利率由货币供求决定，不会立刻随 πᵉ 走；所以"一加息就压通胀预期"的传导没那么干净。
- ⚠️ 翻车点：拿着 1970 年代数据说"高利率＝紧货币"——沃尔克时代名义利率 20% 看着吓人，但通胀 13%，实际利率并不离谱；读利率必须减通胀。
- 🔗 与[[通胀预期]]的暗线：费雪效应成立与否，取决于预期有没有"锚"——央行信誉好，πᵉ 稳定，i 就稳；预期脱锚，名义利率会被通胀绑架。
