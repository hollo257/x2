# 💡 信贷配给

> 🏷️ 一句话：不是利率不够高，是银行干脆"这钱不借"——价格机制在信贷市场失灵了。

## 🧭 四问
- ❓ **是什么**：即使借款人愿意支付现行（甚至更高）利率，银行也拒绝放款的现象。原因是抬高利率会招来[[逆向选择]]（敢赌的人进门）、加剧[[道德风险]]（拿了钱更冒险），银行预期收益反而下降，于是用"数量"代替"价格"出清市场。
- 🗣️ **大白话**：你以为借钱像买东西，贵了少买点就行？在信贷市场，银行是"宁可不卖"。你愿出 15% 利息？银行反而警惕——正常生意谁能稳定赚 15%？敢来借的，多半是赌徒。所以银行的办法是挑人、要抵押、限额，而不是涨价。
- ⚙️ **底层机制**：利率有"双重功能"——定价＋筛选。利率↑→ 剩余借款人平均风险↑（逆向选择）→ 道德风险↑（项目更激）→ 银行违约损失↑，净收益曲线在某个利率后掉头向下。收益最大点上仍有超额需求，但银行不提价，改为配给。
- ⚠️ **争议 / 易错**：配给不是"银行情绪不好"，而是信息约束下的理性结果。它也意味着货币政策传导会堵——央行把水灌到银行体系，银行不贷给小企业，钱就在金融体系里打转（[[货币内生性]]的现场版）。别以为降息就能让所有人借到钱。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 🚫 现象定义：借款人愿意支付挂牌利率，仍得不到贷款；或只能借到小于申请额的部分。
- 🧠 机制：利率↑ → 逆向选择（高风险申请人占比上升）＋道德风险（借款人投更冒险项目）→ 银行净预期收益↓ → 最优做法是**拒绝或限额**。
- 🛠️ 银行对策：[[抵押品]]要求、净值门槛、长期关系、信用评分、行业限额——用非价格条件筛选。
- 📌 政策含义：[[23-货币政策传导机制]]中的"信贷渠道"——即使利率传导顺畅，配给也会让信用紧缩额外冲击企业，尤其伤害无抵押的小企业。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 🧊 隐藏假设：银行是理性的收益最大化者。现实中还有监管资本约束、风险偏好周期、上级行指标——"不借"未必纯是信息问题。
- ⚠️ 翻车点一：把配给当"资金面紧"。经济下行期，企业基本面没坏，银行因为怕（净值下降、抵押品缩水）而集体不借——这就是信贷紧缩，是衰退的放大器。
- ⚠️ 翻车点二：以为降息万能。利率再低，只要银行认为借款人风险高，配给照旧；这正是流动性陷阱附近货币政策失效的另一面。
- 🔗 连锁暗线：配给 ↔ [[抵押品]]缩水 ↔ 净值下降 ↔ [[金融加速器]]——危机时这四者咬合，形成"越差越借不到、越借不到越差"的死循环。
