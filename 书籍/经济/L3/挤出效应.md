# 💡 挤出效应

> 🏷️ 一句话：政府大手花钱把利率抬高，结果企业投资被挤掉了一部分，财政刺激打了折扣。

## 🧭 四问
- ❓ **是什么**：挤出效应（Crowding Out）——政府扩张财政（增支或减税）→ 借钱需求↑ → 利率↑ → 私人投资↓，部分抵消了财政扩张本来想拉动的产出。
- 🗣️ **大白话**：政府也来"抢钱花"，市场上钱就那么多，政府一借把利息顶上去，企业一看借钱贵了就不投了——政府挤进来，企业挤出去。
- ⚙️ **底层机制**：在 [[IS-LM]] 里，财政扩张使 IS 右移，若 LM 向上倾斜，产出↑的同时利率也↑，利率↑压掉私人投资。挤出程度 = 看两条线斜率。
- ⚠️ **争议 / 易错**：挤出程度看斜率——LM 越陡（钱需求对利率越不敏感）挤得越狠；若 LM 平（[[流动性陷阱]]）或 IS 平，则几乎不挤。萧条期产能闲置，常说"无挤出"，别一刀切。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 财政扩张 → IS 右移 → Y↑ 且 i↑ → i↑ 挤出私人投资 I↓。
- 完全挤出：LM 垂直（古典情形），财政只提利率不增产。
- 无挤出：[[流动性陷阱]]下 LM 水平，财政乘数最大。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 潜台词：财政政策到底灵不灵，全押在 LM 斜率上——这就是为什么米什金反复说"政策效果取决于 IS/LM 斜率"。
- 还有"长期挤出"和"李嘉图等价"：今天借的债=明天的税，老百姓提前存钱应对，需求根本没起来——[[理性预期]]派认为挤出比凯恩斯派说的更狠。
- 反例：衰退+闲置产能时，政府花钱能把闲置产能用起来，带动收入回升（"挤进效应"/乘数>1），不挤反拉。
- 它和[[货币政策工具]]是硬币两面：财政要扩、央行配合把利率压住（LM 右移），挤出就消失——政策组合的精髓。
