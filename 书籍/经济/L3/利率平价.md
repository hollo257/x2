# 💡 利率平价

> 🏷️ 一句话：两国利差，会被汇率的预期变动恰好抵消，否则就有人套利。

## 🧭 四问
- ❓ **是什么**：利率平价（IRP, Interest Rate Parity）——无抛补/有抛补条件下，两国利率差等于汇率预期（或远期升贴水），套利资金无利可图。
- 🗣️ **大白话**：你存美国利息 5%、存中国 2%，凭啥？因为市场预期人民币要升、美元要贬，一算账两边收益打平——否则大家全跑去美国存，利差立刻被抹平。
- ⚙️ **底层机制**：跨国套利资金在两国资产间比"换算成同一种货币后的收益率"，收益率低的货币被抛、高的被买，直到利差=预期汇率变动。短期汇率的主力决定机制。
- ⚠️ **争议 / 易错**：现实里有资本管制、交易成本和风险溢价，平价并不严格成立；别把它当成"高息货币一定赚"——高息往往已经被贬值预期吃掉了。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 无抛补利率平价（近似）：本国利率 i ≈ 外国利率 i* + 预期本币贬值率。
- 有抛补利率平价：远期升贴水 = 两国利差。
- 短期汇率由它主导：利差变动 → 资本流动 → 即期汇率跳动。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 隐藏假设：资本自由流动、资产完全可替代、无风险。一旦有风险溢价或资本管制，平价就松——这正是[[不可能三角]]的另一张脸。
- 它解释了"美国加息→美元升"：利差拉大，热钱涌入，[[汇率]]短期走强。
- 套息交易（借低息币买高息币）押的就是"平价短期不成立"，一旦风险偏好逆转，平仓又把汇率打回去——放大波动。
- 与[[费雪效应]]合流：长期利差其实来自通胀差，再经[[购买力平价]]兑现为汇率变动。
