# 💡 汇率

> 🏷️ 一句话：两国货币之间的"比价"，就是一种货币用另一种货币标出来的价格。

## 🧭 四问
- ❓ **是什么**：汇率（Exchange Rate）= 1 单位外币能换多少本币（或反过来），分名义汇率与实际汇率、即期与远期。
- 🗣️ **大白话**：汇率就是"美元多少钱人民币"。你想换美元、海淘、出国旅游，都得看这个价；它一变，你的钱包购买力跟着变。
- ⚙️ **底层机制**：长期看由物价/生产率（[[购买力平价]]）决定；短期由两国利差、资本流动和预期（[[利率平价]]）决定。钱往利息高、经济稳的地方跑，那国货币就升值。
- ⚠️ **争议 / 易错**：短期汇率主要被资本流动和预期牵着走，和"两国谁东西便宜"经常对不上；别以为汇率只看贸易账。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 名义汇率 = 两国货币名义比价；实际汇率 = 名义汇率经两国物价调整后的相对商品价格。
- 本币升值 → 出口变贵、进口变便宜；本币贬值 → 出口便宜、进口变贵。
- 短期：美国加息 → 美元资产吸引力↑ → 美元升值（[[利率平价]]逻辑）。
- 长期：购买力平价决定汇率的长期走势（[[购买力平价]]）。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 书上"长期 PPP、短期利差"的分工，藏着一个假设：价格短期粘住不动，所以短期只能靠资本流动来出清。
- 汇率不是"浮"在真空里，它和汇率制度绑死：[[不可能三角]]里你选了固定汇率，汇率这根价格就被政府按死了。
- 预期是自我实现的：大家都觉得本币要贬，就抢着换汇，央行外储被抽干，真贬了——这就是[[货币危机]]的种子。
- 汇率还是货币政策的一条隐藏传导管子：[[传导机制]]里的汇率渠道，本币贬会输入通胀、刺激出口。
