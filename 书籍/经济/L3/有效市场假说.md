# 💡 有效市场假说

> 🏷️ 一句话：公开信息会迅速、充分地反映进价格——你很难持续跑赢大盘，尤其靠"打听消息"。

## 🧭 四问
- ❓ **是什么**：有效市场假说（EMH）认为，证券价格充分、及时反映所有可得信息。按信息集宽度分三档：弱式（历史价格已反映）、半强式（所有公开信息已反映）、强式（连内幕信息也反映，现实中最弱）。
- 🗣️ **大白话**：利好消息一出来，机构算法毫秒级抢跑，等你在新闻上看到，价格早就涨完了。所以"听到利好再买"往往是接盘，长期靠公开信息反复赚超额收益基本没戏——这不是你笨，是市场已经把账算完了。
- ⚙️ **底层机制**：建立在[[理性预期]]＋套利之上——任何价格偏离内在价值，都会被套利者迅速抹平；只要足够多聪明人盯着，价格就是对所有信息的无偏汇总。
- ⚠️ **争议 / 易错**：有效市场 ≠ 价格永远正确，而是"你无法持续战胜市场"。它更不等于"市场不会疯"——泡沫、崩盘、动量、日历效应都在打脸；[[行为金融]]指出套利有成本有极限，噪音交易者能把价格带离价值很久很久。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 📊 定价基础：股价＝未来股利/盈利的预期现值（戈登增长模型 P₀＝D₁/(k－g)）；EMH 说这一现值已被当前价格充分编码。
- 🧪 三档信息强度：弱式（技术分析无效）、半强式（基本面分析也难持续超额）、强式。
- 📌 操作含义：①技术分析图表基本无效；②"内幕消息"才可能超额（且违法）；③被动指数投资是普通人的理性选择；④消息出尽即price in——利好兑现日反而常跌。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 🧊 隐藏假设：套利无成本、无风险、资本无限。现实中"价值与价格偏离"可能持续数年（凯恩斯：市场保持非理性的时间，长过你保持偿付能力的时间）——套利受限，价格就能一直错。
- 🧠 被[[行为金融]]狙击：过度自信、羊群效应、损失厌恶、锚定——人系统性犯错，且错误相关（不是随机噪音），于是趋势、泡沫、崩盘成了规律而非例外。
- ⚠️ 翻车点：把"市场难战胜"读成"价格总是对的"——2000 互联网泡沫、2008 前的房价，价格都长期远离"内在价值"；EMH 解释不了泡沫为什么形成，只能解释泡沫"事后才知道"。
- 🔗 与[[理性预期]]的暗线：EMH 是理性预期在资产定价上的应用；[[政策无效性命题]]则是它在宏观政策上的姊妹篇。
