# 💡 抵押品

> 🏷️ 一句话："还不上钱，这东西归我"——用借款人自己的资产做人质，压住信息不对称的两把火。

## 🧭 四问
- ❓ **是什么**：借款人承诺违约时交给贷款人处置的资产（房产、设备、应收账款、金融资产）。它是债务合同里降低[[逆向选择]]与[[道德风险]]的核心装置。
- 🗣️ **大白话**：银行凭什么敢借钱给一个它不完全了解的人？因为你把房子押上了——敢乱来、敢跑路，房子就没了。抵押品把"借款人的钱包"和"银行的风险"绑在一起：他自己的钱在里面，他就不敢赌。
- ⚙️ **底层机制**：两层作用——①逆向选择筛选：烂项目/烂项目主拿不出值钱抵押，自动知难而退；②道德风险约束：押品让借款人损失与银行绑定，行事更谨慎。宏观上，**外部融资溢价是借款人净值（含抵押品）的减函数**——净值越高，借钱越便宜。
- ⚠️ **争议 / 易错**：抵押品不是越多越好，它是顺周期放大器——房价涨，抵押品值钱，大家借得更多、把房价推得更涨；房价跌，抵押品缩水，贷款条件瞬间收紧，哪怕借款人没做错任何事。抵押品也会贬值：房市跌、股市跌，"押品"一夜变"废品"。

## 🟢 显性层（书上明写：定义 / 公式 / 结论）
- 🛡️ 微观作用一（事前）：[[逆向选择]]的筛选器——有抵押的项目银行才敢看，无抵押者只能付更高溢价或直接被拒（[[信贷配给]]）。
- 🛡️ 微观作用二（事后）：[[道德风险]]的缰绳——押品归债权人，借款人乱冒险的代价内部化。
- 📐 宏观关系：**外部融资溢价 ＝ f(借款人净值)**，净值（抵押品＋留存收益）越高，溢价越低，投资越旺——这就是[[金融加速器]]的核心公式。
- 📌 实证事实：小企业融资更依赖抵押与关系贷款，正因为它们信息不透明、无抵押就出局。

## 🟣 隐性层（隐藏假设 / 潜台词 / 争议 / 翻车点）
- 🧊 隐藏假设：抵押品价格稳定、变现容易。现实中抵押品（尤其是房产）本身就是周期性资产，银行"要抵押"的行为在放大周期，不是对冲周期。
- ⚠️ 翻车现场：房价/股价下跌 → 抵押品市值缩水 → 借款人净值下降 → 新贷款更少 → 被迫甩卖资产 → 价格再跌……这就是[[金融加速器]]与[[流动性螺旋]]的连环扣。
- 🏚️ 次贷现场：[[2008次贷危机]]里，"房价永远涨"让 LTV（贷款/房价比）越放越高，抵押品神话在房价拐点瞬间破碎——押了等于没押。
- 🎯 潜台词：抵押品制度本质是"不信任你的人品，只信你的资产"；它把信任问题暂时转嫁给资产价格，于是金融体系的稳定性反过来依赖资产泡沫不破——这是深层悖论。
