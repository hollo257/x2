# 🏦 P3-金融机构篇

> 🧭 **一句话定位**：为什么银行和间接融资这么重要——一切围绕**信息不对称**展开，直到危机爆发与监管补漏。

## 🎯 本篇主线
- 🔍 [[信息不对称]] → 交易前[[逆向选择]] + 交易后[[道德风险]] → 需要[[金融中介]]筛人、盯人、要[[抵押品]]。
- 💥 危机链条：资产泡沫 + 高杠杆 + 流动性错配 → 挤兑/抛售 → 信贷冻结（[[金融加速器]]、[[明斯基时刻]]、[[流动性螺旋]]、[[系统风险]]）。
- 🛡️ 监管为何而来：[[银行挤兑]]外部性、[[存款保险]]、[[巴塞尔协议]]、[[宏观审慎]]、[[最后贷款人]]；[[影子银行]]与[[证券化]]是创新也是绕监管。
- ⚠️ 易错：单家银行稳 ≠ 系统稳；监管在安全与效率间找平衡。
