# 🧭 P1-导言篇

> 🧭 **一句话定位**：全书的"开机键"——先搞懂货币、银行、金融市场到底是干嘛的，资金怎么从储蓄者流到借款者手里。

## 🎯 本篇主线
- 🏦 金融的本质：把"有钱没处花的人"的钱，转给"缺钱能生钱的人"，中间要解决**信任、风险、期限**三件事。
- 🔗 链条：[[货币]]影响利率与通胀 → [[金融中介]]筛人、监督、兜底 → 资金配置到实体经济。
- ⚠️ 易错：[[货币]] ≠ 财富 ≠ 收入；二级市场不直接给企业新钱，但提供流动性。
