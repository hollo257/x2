# 🌍 P5-国际金融篇

> 🧭 **一句话定位**：国门打开后，汇率怎么定、国际货币体系怎么运转、为什么会爆发[[货币危机]]。

## 🎯 本篇主线
- 💱 [[汇率]] = 两国货币的比价：长期看[[购买力平价]]，短期看[[利率平价]]与资本流动、预期。
- 🔺 [[不可能三角]]：固定汇率、资本自由流动、独立货币政策，三者只能选两个。
- 💥 [[货币危机]]：固定汇率 + 资本外逃 + 预期自我实现 → 外储耗尽。
- 🇪🇺 欧元与最优货币区：哪些国家适合共用一种货币？
- ⚠️ 易错：没有完美汇率制度，只有权衡；短期汇率受资本流动和预期影响极大。
