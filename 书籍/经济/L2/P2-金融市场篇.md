# 📊 P2-金融市场篇

> 🧭 **一句话定位**：给"钱"和"风险"定价——利率怎么算、为什么高低不一、股价怎么定、市场到底有效没效。

## 🎯 本篇主线
- 💯 利率是资金的价格，也是把未来现金流折到今天的折扣率（[[到期收益率]]、[[利率风险]]、[[费雪效应]]）。
- 🧗 风险结构看违约/流动性/税收，期限结构看预期与期限偏好（[[收益率曲线]]）。
- 🧠 股价 = 未来现金流现值；[[理性预期]]下价格反映信息，但[[行为金融]]说人没那么理性。
- ⚠️ 易错：债券价格与利率反向；收益率曲线倒挂常被当衰退信号但非绝对；[[有效市场假说]]≠ 价格永远对。
