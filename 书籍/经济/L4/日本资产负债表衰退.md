# 🌍 日本资产负债表衰退

- ⏰ 时间：1990 年泡沫破裂后，贯穿 1990 年代–2000 年代（"失去的十年/二十年"）
- 📍 地点 / 主体：日本；主角是地价股价泡沫破裂后的企业与家庭部门、日本央行
- 🔗 机制链条：
  1. 1980 年代低利率催生地价、股价巨大泡沫。
  2. 1990 年泡沫破裂 → 资产价格暴跌 → 企业家庭资产端缩水、负债端不变，技术性资不抵债（[[资产负债表衰退]]启动）。
  3. 私人部门集体把目标从"利润最大化"切到"还债"：不投资、不消费、不借钱。
  4. 央行把利率一路降到零附近 → 掉进[[流动性陷阱]]：[[IS-LM]] 里 IS 整体左移塌缩，再便宜的钱也无人借，货币政策失效。
  5. 政府被迫持续财政扩张填需求窟窿（且几乎无[[挤出效应]]，因利率已贴地）。
  6. 后续动用[[量化宽松]]等非常规工具，但复苏缓慢。
- 📉 结果：长期低增长、通缩压力、零利率；成为资产负债表衰退与[[流动性陷阱]]的全球教科书样本；也促使央行研发 QE、[[负利率]]、前瞻指引等新工具。
