# 🌍 欧债危机

- ⏰ 时间：2010–2012 年（希腊 2009 年底暴露，2010 年起蔓延）
- 📍 地点 / 主体：欧元区 periphery（希腊、爱尔兰、葡萄牙、西班牙、意大利）；主角是统一货币下的主权债务与银行体系
- 🔗 机制链条：
  1. 欧元诞生 = 成员国放弃[[汇率]]与独立货币政策（[[不可能三角]]选了"固定汇率+资本自由流动"，把货币政策交给欧央行）。
  2. 加入欧元区 periphery 融资利率大降，政府与私人部门大举借债、内部工资物价竞争力下滑。
  3. 2008 危机后财政恶化，希腊财政赤字曝光 → 主权国债利差飙升、[[货币危机]]式的自我实现预期（大家怕违约→利率↑→越还不起→真违约）。
  4. 银行持有本国国债，国债跌→银行资产负债表受损→银行危机与主权危机"恶性交织"。
  5. 不能贬值、不能独立印钞，只能靠内部贬值（紧缩工资物价），[[资产负债表衰退]]式痛苦调整。
- 📉 结果：多国接受 EFSF/ESM 与欧央行（OMT 等）救助； periphery 长期高失业、紧缩争议巨大；暴露欧元区"货币统一、财政未统一"的制度缺陷。
