# 🌍 恶性通胀

- ⏰ 时间：经典案例为 1920 年代初魏玛德国（1918–1923）；津巴布韦、委内瑞拉等为现代版本
- 📍 地点 / 主体：魏玛共和国德国为教科书原型；主角是财政赤字货币化、央行独立性缺失
- 🔗 机制链条：
  1. 政府巨额财政赤字（战后赔款+支出），又借不到足够市场债 → 只能让央行印钱补贴（财政赤字货币化、靠铸币税式通胀税）。
  2. 按[[数量论]] MV=PY：M 暴增、V 飙升（人人急着花）→ P 天文数字上涨。
  3. 工人要求工资随物价指数化、[[通胀预期]]脱锚——今天不涨价明天更不值钱，定价行为自我加速。
  4. 货币迅速失去价值储藏职能，人们拒用本币、回归物物交换/外币化。
  5. [[购买力平价]]暴力回归：本币汇率随物价狂奔式贬值。
- 📉 结果：物价按月甚至按天翻倍、储蓄清零、经济紊乱；根治办法是财政货币改革+重建[[名义锚]]与央行独立性（[[央行独立性]]的经典论据）。
