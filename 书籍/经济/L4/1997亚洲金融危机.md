# 🌍 1997亚洲金融危机

- ⏰ 时间：1997–1998 年（1997 年 7 月泰铢失守引爆）
- 📍 地点 / 主体：泰国始发，蔓延印尼、韩国、马来西亚、菲律宾等；盯住美元的新兴市场与国际炒家
- 🔗 机制链条：
  1. 各国把[[汇率]]盯住美元，同时开放资本账户——踩中[[不可能三角]]的雷：名义固定+资本流动+想保独立货币政策。
  2. 短期外债大量借入、资产价格泡沫膨胀，[[金融加速器]]把繁荣放大。
  3. 经常账恶化、信心转弱，炒家攻击泰铢。
  4. 央行动用外储护盘失败 → 外储耗尽 → 固定汇率崩溃（[[货币危机]]）。
  5. 本币暴跌 → 以美元计的外债暴增 → 企业银行资产负债表打穿 → 连锁倒闭、[[流动性螺旋]]式甩卖。
  6. IMF 附带紧缩与改革条件的救助介入。
- 📉 结果：东南亚货币大幅贬值、资本外逃、衰退与企业银行倒闭潮；暴露"双危机"（货币危机+银行危机）叠加；促使新兴市场积累外储、反思[[汇率]]制度选择。
