# 🌍 2008次贷危机

- ⏰ 时间：2007–2009 年（以 2008 年 9 月雷曼倒闭为高潮）
- 📍 地点 / 主体：美国始发，席卷全球；主角是美国次贷市场、[[证券化]]链条（MBS/CDO）、CDS 与影子银行体系
- 🔗 机制链条：
  1. 长期低利率 + 房价只涨信念 → 银行把贷款借给还不起的人（次贷）。
  2. [[证券化]]把次贷打包成 CDO，[[影子银行]]靠回购短融长持，杠杆越堆越高。
  3. 融资结构滑向[[明斯基时刻]]里的庞氏段：靠房价续涨续命。
  4. 房价见顶回落 → 房贷违约 → CDO 减值 → [[金融加速器]]反向放大（净值↓→信贷↓）。
  5. 回购市场 haircut 飙升 → [[流动性螺旋]]：被迫甩卖、价格暴跌、机构挤兑。
  6. 雷曼倒闭 → 全球信贷冻结、[[系统风险]]爆发，央行当[[最后贷款人]]+最后做市商。
- 📉 结果：全球金融危机、衰退、失业飙升；家庭部门[[资产负债表衰退]]式去杠杆；催生 Dodd-Frank 与[[巴塞尔协议]]资本新规、[[宏观审慎]]框架。
